mk-emoji-picker

让文本框或可编辑 div 拥有插入表情的能力。自动识别元素类型，支持多分组切换、表情代码转换与同一页面多实例。

About

说明

v2 已全面重写为原生 JavaScript，不再依赖 jQuery，并由 esbuild 自动构建发布。

相对 v1 的变化

  • 移除 jQuery 与 mCustomScrollbar 等全部运行时依赖
  • 源码拆分为 ESM 模块，产出 IIFE / ESM / CJS 与 CSS
  • 新 API：create() / parse() / destroy()
  • 面板类名统一为 .mkep-* 前缀，避免全局污染
  • Grunt 换成 esbuild，GitHub Release 自动构建产物

保留的能力

  • 表情图片按可视区域懒加载
  • 面板网格随容器自适应，消除每行右侧留白
  • 小屏自动缩小格子，切换分组时回到顶部
  • 贴吧、QQ、微博、阿鲁全套表情与拼音文件名
  • 文档页语义化结构、深色模式与响应式布局

Features

功能

一个零依赖的轻量组件，可用于表单输入、评论框与富文本编辑区域。

  • 支持给 textarea 或可编辑 div 加上表情功能，自动识别元素类型。
    Support for textarea and contenteditable.
  • textarea 插入表情代码，可编辑 div 直接插入表情图片。
    Insert code or image depending on the field type.
  • 支持自定义表情代码格式，占位符中的正则元字符按字面量匹配。
    Fully customizable placeholder.
  • 支持把文本中的表情代码转换为图片，只处理正文文本节点。
    Parse codes into images without touching scripts or attributes.
  • 支持多组表情并提供 Tab 切换，Tab 使用原生 button 与 ARIA 角色。
    Multiple groups with accessible tabs.
  • 同一页面支持多个实例，destroy() 会解绑全部事件。
    Multiple instances with explicit teardown.
  • 表情图片按需加载，网格随容器宽度自适应，移动端可用。
    Lazy-loaded images and responsive grid.
  • 支持深色模式、减少动态效果、键盘焦点与 Esc 关闭。
    Dark mode, reduced motion and keyboard support.

Options

参数

调用 create(target, options) 时可传入以下配置。

名称 name 类型 type 默认值 default 说明 desc
button Element / String null 触发面板的按钮；不指定则自动创建一个按钮。
trigger button; auto-created when empty.
container Element / String document.body 面板与自动按钮的挂载容器。
showTab Boolean true 只有一组表情时是否仍然显示 Tab。
animation String 'fade' 'fade' / 'slide' / 'none'；系统开启减少动态效果时自动禁用。
basePath String '' 表情图片文件的根路径，如 'images/emoji'。
icons Array [] 必填。表情分组配置。
icons:{ path } String — 必填。该组子目录；最终路径 = basePath + 该路径 + 文件名 + 后缀。
icons:{ name } String group(n) Tab 上显示的分组名称。
icons:{ maxNum } Number — 未配置 icons:{ emoji } 时必填，按数字文件名生成。
icons:{ emoji } Object — {"微笑": "weixiao"} 形式的显示名 → 文件名映射。
icons:{ placeholder } String '#em(n)_{alias}#' 插入文本框的代码模板，必须包含 {alias}。
icons:{ excludeNums } Array [] 要跳过的序号集合。
icons:{ file } String '.jpg' 表情文件后缀名。
onSelect Function null (code, src) => {}，选中表情后触发。
onShow / onHide Function null 面板显示 / 隐藏动画结束后触发。

* n：分组的次序 index of the group

Theme

主题定制

组件外观全部由 CSS 变量控制，不需要修改源码。无 data-theme 时跟随系统偏好。

Migration

从 v1 迁移

v2 是破坏性升级：不再注册 jQuery 插件方法，类名也统一为 .mkep-* 前缀。

配置项 button / showTab / animation / basePath / icons 保持兼容；全局表情列表由 emojiLists 改为 window.mkEmojiLists。完整对照表见 README。
