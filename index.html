jQuery-emoji

让文本框或可编辑 div 拥有插入表情的能力。自动识别元素类型，支持多分组切换、表情代码转换与同一页面多实例。

About

说明

此插件在 @eshengsky 的基础上修改而来。

相对原版的改动

  • 新增表情列表根文件目录设置
  • 删除对 mCustomScrollbar 的依赖
  • 更改表情配置方式
  • 修改表情预览框位置的判定方式
  • 增加对移动端的兼容
  • 整合了贴吧、QQ、微博、阿鲁全套表情

近期优化

  • 表情图片按可视区域懒加载，打开面板不再一次性请求全部图片
  • 面板网格列宽随容器自适应，消除每行右侧留白
  • 小屏幕自动缩小格子，切换分组时回到顶部
  • 图片文件名统一为拼音，避免不同系统下的编码问题
  • 文档页重构为语义化结构，支持深色模式与响应式布局

Features

功能

一个依赖 jQuery 的轻量插件，可用于表单输入、评论框与富文本编辑区域。

  • 支持给 textarea 或可编辑 div 加上表情功能，自动识别元素类型。
    Support for adding emoji into textarea or editable div, automatic identification of element types.
  • 如果是 textarea，选择表情后插入表情代码；如果是可编辑 div，则直接插入表情图片。
    Insert code string for textarea, or the emoji picture for editable div.
  • 支持自定义表情代码的格式。
    Support for specifying the code format of emoji.
  • 支持将表情代码转换为表情图片。
    Support for converting the code string of emoji into emoji picture.
  • 支持多组表情并提供 Tab 切换。
    Support for multiple groups of emoji and tabs to toggle.
  • 示例已带有 QQ、贴吧、微博、阿鲁全套表情。
  • 同一页面支持多个表情实例。
    Support for multiple instances in one page.
  • 表情图片按需加载，网格随容器宽度自适应，移动端可用。
    Lazy-loaded images and responsive grid for small screens.

Usage

使用

无需构建步骤，引入样式与脚本后即可调用。

安装 install

克隆仓库后直接引用 dist/ 下的文件。

调用 invoke

在文本框或可编辑 div 上初始化表情。
initialize emoji on textarea or editable div

引用 reference

Options

参数

调用 .emoji(options) 时可传入以下配置。

名称 name 类型 type 默认值 default 说明 desc
button String — 触发表情面板的按钮选择器，如 "#btn1"；指定则将面板绑定到该按钮，未指定则自动创建一个按钮。
button selector; if empty, a button is created automatically.
showTab Boolean true 当只有一组表情时，是否仍然显示 Tab。
if show tab when only one emoji group.
animation String 'fade' 表情面板动画效果：'fade' 淡入淡出、'slide' 滚动、'none' 无动画。
'fade': fade-in fade-out, 'slide': slide up & down, 'none': no animation.
basePath String — 表情图片文件的根路径。
icons Array [] 表情组。
icons group.
icons:{ name } String group(n) 该组表情名称。
the name of the icons group.
icons:{ path } String — 必填。该组表情路径（最终路径 = basePath + 这里的独立路径）。
required. the path of the icons group.
icons:{ maxNum } Number — 未配置 icons:{ emoji } 时必填。该组表情文件名的最大数。
required. the max number of the icons group file name.
icons:{ excludeNums } Array [] 要排除的表情文件集合。
the exclude icon files.
icons:{ file } String '.jpg' 表情文件的后缀名。
the icon file extension.
icons:{ placeholder } String '#em(n)_{alias}#' 该组表情插入文本框后的占位标识，必须包含 {alias}，会被替换成每个表情的标识。
the placeholder, must contain '{alias}'.
icons:{ emoji } Object — 每个表情的名字与对应文件名，格式如 {"表情一":"pic1", "表情二":"pic2"}。

* n：分组的次序 index of the group

Methods

方法

初始化之后可通过字符串参数调用以下方法。

.emoji(options);

初始化表情。
initialize emoji.

.emoji('show');

显示表情面板。
show emoji panel.

.emoji('hide'); / .emoji('toggle');

隐藏 / 切换显示隐藏表情面板。
hide or toggle emoji panel.
